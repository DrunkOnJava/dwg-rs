# ODA spec v5.4.1 coverage

Last measured 2026-10-21, on `main` at `b268e884`.

One row for every section of the *Open Design Specification for .dwg files* v5.4.1 (Open Design Alliance), the specification dwg-rs is built from, with its state on `main`, the code that implements it and the issue that tracks what is left. The data is in [`data/spec-coverage.tsv`](data/spec-coverage.tsv). The summary and the section table below are generated from it by `tools/ci/spec_coverage.py --write`, and CI fails when they differ or when a section of the spec has no row.

| State | Meaning |
|---|---|
| `missing` | No decoder. |
| `decoder` | Implemented, but no corpus record measures it. |
| `partial` | Known incomplete, or erroring on some corpus record. |
| `closes` | Ends on its exact boundary on every corpus record of the type. Values not yet checked against AutoCAD. |
| `complete` | Closes on every release band, R13 to R2018, and every value equals AutoCAD's DXF export of the same drawing. |

`closes` comes from the boundary checks on a local 19-file corpus (STATUS.md, 2026-08-30) and is re-measured in CI by the 0.2.0 measurement work. Values are measured by the DXF value oracle (`examples/dxf_oracle`, #99), which pairs every DWG record of those drawings with AutoCAD's own DXF export of the same drawing by handle and compares every decoded field with its DXF group; each row it measures says so in its note. No row is `complete`: that needs every release from R13, and the corpus has no R13 drawing and no R14 export that carries handles on its tables and objects. A state changes only in the pull request that brings its evidence ([`maintaining.md`](maintaining.md)).
