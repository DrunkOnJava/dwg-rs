# dwg-wasm sample fixtures

Tiny synthetic DWG files bundled with `dwg-wasm` so a browser viewer
can load a real file without the user having to supply one. Served by
the V-20 `DwgFile.openSample(name)` JS entry point (see
`wasm/src/sample_loader.rs`).

## Provenance

Committed on 2026-04-20 (`f5bd374`), generated by `tools/synthetic-dwg`, a small
crate outside the workspace that has since been removed (#20): `examples/build_fixtures.rs`
supersedes it, and nothing in the tree builds or reads it. Its source is in
git history (`git show e7c53e1:tools/synthetic-dwg/src/main.rs`). It emitted a
minimal R14 (AC1014) file: magic + common prefix + five 9-byte locator
records + a fake LINE entity payload. The file round-trips through
`dwg::DwgFile::open` but is NOT guaranteed to open in AutoCAD; these are
test fixtures, not AutoCAD-authored drawings.

The four files are committed as they were generated and nothing in the tree
regenerates them. The reader's real fixtures are `tests/fixtures/canonical/`
(written by `examples/build_fixtures.rs`, R2000 to R2018) and the public
corpus pinned in `tools/corpus/pins.tsv`.

the name-to-content mapping above is the shape the names were meant to have,

names still exercise the sample-loader's `fetch` path + URL routing, which is
the purpose of V-20.
